# Running Line

Application web (single-page, `index.html`) pour générer des parcours de course à pied sur une carte interactive et les exporter au format GPX.

## Fonctionnalités

- Génération de parcours selon le lieu, la distance et le type de terrain
- Visualisation sur carte (OpenStreetMap, OpenTopoMap, satellite, CyclOSM, CartoDB dark)
- Sauvegarde des parcours générés
- Export au format GPX, importable dans des applications comme Strava

## Utilisation

Ouvrir `index.html` dans un navigateur, aucune installation ni build n'est nécessaire.
